# Profile README setup

1. Create/open the repository `irannaSJ/irannaSJ`.
2. Replace its README.md with the included README.md.
3. Upload the `assets/` directory.
4. Upload `.github/workflows/snake.yml`.
5. Commit to `main`.
6. Run the snake workflow once from Actions -> Generate contribution snake -> Run workflow.
7. After the first run, the snake SVG will be committed into `assets/`.

The hero and logo are self-contained SVG assets. GitHub may sanitize some SVG animation behavior; if the hero appears static, it will still render as a polished banner.
