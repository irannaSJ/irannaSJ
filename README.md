## 🚀 What I'm Working On

### WorkPulse — Offline-first Employee Platform

A modern employee attendance application built with **Kotlin + Jetpack Compose**, designed around an offline-first architecture.

**Current engineering focus**

- 📱 Android + Jetpack Compose
- 🧱 MVVM + Clean Architecture principles
- 💾 Room as the local source of truth
- 🔐 DataStore-based session management
- 🌐 Retrofit + OkHttp for backend communication
- 🧩 Hilt dependency injection
- 📍 Location-aware attendance
- 🔄 Background synchronization with ERPNext
- ⚡ Offline punch-in / punch-out workflows

The application uses **ERPNext HRMS as the authentication and synchronization backend**, while keeping day-to-day app data locally available for resilient offline usage.

### ERPNext / Frappe Development

I'm also working with **ERPNext v15 / Frappe** to build and customize business workflows using maintainable app-level Python logic, DocTypes, APIs, and backend integrations.
